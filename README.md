# AI Slide Generator

Generate professional, single-slide decks for business analysis with one click.
The Streamlit application leverages OpenAI's GPT-4o and o3 model to draft content,
then renders a high-quality HTML/PDF slide locally—so no web front-end or
PowerPoint licence is required.

## ✨ What It Does

1. **4P Analysis Slide** – Marketing-mix analysis (Product, Price, Place, Promotion)
   with an autogenerated strategic header.
2. **Company Financial Slide** – Multi-year revenue & EBIT bar charts plus a
   concise performance summary.

Both slide types are delivered as:
• An on-screen HTML preview inside Streamlit
• A downloadable, print-ready PDF (1280×720 or A4 landscape, depending on the template)

## 📁 Repository Layout

```
.
├── app.py                 Entry point – Streamlit sidebar + page routing
├── slide_4p.py            4P Analysis logic & template injection
├── slide_financial.py     Financial slide logic & template injection
├── 4p_template.html       Static HTML/CSS template for 4P slide
├── Financial performance.html  Static HTML/CSS/JS template for financial slide
├── requirements.txt       Runtime dependencies
└── .streamlit/secrets.toml  Your OpenAI API key (NOT committed)
```

## 🚀 Quick Start

```bash
# 1.  Install Python packages (Python ≥ 3.9)
$ pip install -r requirements.txt

# 2.  Add your OpenAI key
$ mkdir -p .streamlit
$ printf "OPENAI_API_KEY=sk-..." > .streamlit/secrets.toml

# 3.  Launch the app
$ streamlit run app.py
```

Open the local URL shown in the terminal, choose a slide type from the sidebar,
enter a company name, and click **Generate**. The slide will appear within
~15 seconds (depending on model latency).

## 🔒 Security Notes

The OpenAI key is read from `.streamlit/secrets.toml` at runtime; the file is
listed in `.gitignore` to avoid accidental commits. No data is sent anywhere
except the OpenAI API endpoint.

## 🛠️ Customisation Tips

• **Styling** – Edit the corresponding HTML template to change colours,
  fonts or page size. WeasyPrint converts the same HTML to PDF.
• **Additional Slide Types** – Follow the structure in `slide_4p.py` or
  `slide_financial.py` and add a new module plus a template.
